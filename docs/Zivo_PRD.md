# سند نیازمندی‌های محصول (PRD)

## فروشگاه آنلاین لباس زیر و پوشاک بانوان «زیوو \| Zivo»

**نسخه:** 1.0\
**نوع پروژه:** Mock / Frontend Prototype\
**زبان:** فارسی\
**جهت رابط کاربری:** RTL\
**پلتفرم:** وب Responsive، Mobile-first\
**فناوری‌های اصلی:** React، Next.js، Tailwind CSS، shadcn/ui\
**فونت:** Vazirmatn

------------------------------------------------------------------------

# 1. معرفی محصول

«زیوو» یک فروشگاه آنلاین مدرن، لوکس و حرفه‌ای در حوزه پوشاک بانوان است که
تمرکز اصلی آن بر فروش:

-   لباس زیر زنانه
-   سوتین
-   شورت
-   ست لباس زیر
-   لباس خواب
-   لباس شب
-   بادی و گن
-   لوازم جانبی مرتبط
-   سایر محصولات پوشاک بانوان

است.

هدف پروژه، طراحی یک **Mock کامل و نزدیک به محصول واقعی** است؛ به‌گونه‌ای
که ظاهر، تجربه کاربری، ساختار صفحات، رفتار کامپوننت‌ها، حالت‌های مختلف
رابط کاربری و جریان خرید تا حد امکان مشابه یک فروشگاه آنلاین
Production-grade باشد.

در این فاز تمرکز اصلی روی **UI/UX، معماری فرانت‌اند، تجربه کاربری،
Responsive Design، تعاملات و شبیه‌سازی رفتارهای واقعی فروشگاه** است و
اتصال واقعی به Backend، درگاه پرداخت و دیتابیس جزو محدوده این Mock نیست؛
اما معماری رابط باید به شکلی طراحی شود که در آینده بتوان Backend واقعی
را بدون بازطراحی اساسی به آن متصل کرد.

# 2. اهداف اصلی پروژه

## 2.1 اهداف محصول

1.  ایجاد یک تجربه خرید آنلاین لوکس، ساده و قابل اعتماد.
2.  ایجاد هویت بصری متمایز برای برند Zivo.
3.  نمایش حرفه‌ای محصولات و تصاویر آن‌ها.
4.  فراهم کردن جستجو، فیلتر و مرتب‌سازی سریع محصولات.
5.  ایجاد جریان خرید ساده از محصول تا Checkout.
6.  طراحی تجربه‌ای Mobile-first و شبیه اپلیکیشن در موبایل.
7.  ایجاد سیستم حساب کاربری کامل.
8.  ایجاد ساختار قابل توسعه برای اتصال به API واقعی در آینده.
9.  رعایت استانداردهای مدرن UI/UX، Accessibility، Performance و SEO.
10. ایجاد یک Design System منسجم که تمام صفحات از آن پیروی کنند.

-   60٪: Ivory / Cream
-   20٪: White Warm
-   10٪: Dark Brown
