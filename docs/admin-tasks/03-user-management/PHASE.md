### 2. DataTable

**کامپوننت:** `components/admin/data-table/data-table.tsx`

**ستون‌ها:**

| ستون | فیلد | قابلیت Sort | قابلیت Filter | فرمت |
|------|------|-------------|---------------|------|
| ID | id | بله | خیر | عدد |
| نام | name | بله | جستجو | متن |
| موبایل | mobile | بله | جستجو | LTR |
| ایمیل | email | بله | جستجو | - |
| وضعیت | isActive | بله | چندانتخابی | Badge (سبز/قرمز) |
| تعداد سفارشات | _count.orders | بله | خیر | عدد |
| تاریخ ثبت‌نام | createdAt | بله (پیش‌فرض: جدید) | بازه تاریخ شمسی | شمسی |
| عملیات | - | خیر | خیر | دکمه‌ها |

**فیلترهای پیشرفته:**
- جستجوی آزاد (نام + موبایل + ایمیل)
- فیلتر وضعیت: همه / فعال / غیرفعال
- فیلتر تاریخ ثبت‌نام: بازه شمسی
- فیلتر تعداد سفارشات: بیشتر از / کمتر از

**مرتب‌سازی:**
- کلیک روی هدر ستون
- جهت صعودی/نزولی
- پیش‌فرض: جدیدترین

**صفحه‌بندی:**
- گزینه‌ها: 10 / 25 / 50 / 100
- نمایش صفحه فعلی
- دکمه‌های قبلی/بعدی

### 5. API Routes

**GET `/api/admin/users`**
```
Query: page, pageSize, search, status, sortBy, sortOrder, dateFrom, dateTo
Response: { success, data: User[], meta: { total, page, pageSize, totalPages } }
```

**GET `/api/admin/users/[id]`**
```
Response: { success, data: UserWithStats }
```

**PATCH `/api/admin/users/[id]`**
```
Body: { name?, email?, isActive? }
Response: { success, data: User }
```

**Prisma Query Example:**
```typescript
const users = await prisma.user.findMany({
  where: {
    ...(search && {
      OR: [
        { name: { contains: search } },
        { mobile: { contains: search } },
        { email: { contains: search } },
      ],
    }),
    ...(status === "active" && { isActive: true }),
    ...(status === "inactive" && { isActive: false }),
  },
  include: {
    _count: { select: { orders: true } },
  },
  orderBy: { [sortBy]: sortOrder },
  skip: (page - 1) * pageSize,
  take: pageSize,
});

const total = await prisma.user.count({ where: sameFilters });
```
