### 3. فرم بروزرسانی وضعیت

**کامپوننت:** `components/admin/forms/order-status-form.tsx`

- Select وضعیت جدید
- یادداشت ادمین (Textarea)
- دکمه ذخیره
- تأیید قبل از ارسال

**تغییرات خودکار هنگام بروزرسانی وضعیت:**
- processing → ثبت `processing_at`
- shipped → ثبت `shipped_at`
- delivered → ثبت `delivered_at`
- cancelled → ثبت `cancelled_at`
- returned → ثبت `returned_at`

### 4. Timeline سفارش

**کامپوننت:** `components/admin/charts/order-timeline.tsx`

- نمایش خطی تاریخچه وضعیت‌ها
- هر مرحله: تاریخ + وضعیت + یادداشت + نام ادمین
- مرحله فعلی با رنگ primary
- مراحل آینده کمرنگ

### 5. API Routes

```
GET    /api/admin/orders               → list with advanced filters
GET    /api/admin/orders/[id]          → full order with items, history, user
PATCH  /api/admin/orders/[id]          → update status (creates history)
PATCH  /api/admin/orders/[id]/note     → update admin_note only
```

**بروزرسانی وضعیت با Transaction:**
```typescript
await prisma.$transaction(async (tx) => {
  // بروزرسانی وضعیت سفارش
  await tx.order.update({
    where: { id: orderId },
    data: {
      status: newStatus,
      ...(newStatus === "shipped" && { shippedAt: new Date() }),
      ...(newStatus === "delivered" && { deliveredAt: new Date() }),
      ...(newStatus === "cancelled" && { cancelledAt: new Date() }),
    },
  });

  // ایجاد رکورد در تاریخچه
  await tx.orderStatusHistory.create({
    data: {
      orderId,
      status: newStatus,
      note,
      adminId: admin.id,
    },
  });
});
```
