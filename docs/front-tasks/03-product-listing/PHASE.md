# فاز 03 — Product Listing (PLP)

## هدف فاز

ساخت `ProductCard` به‌عنوان یکی از مهم‌ترین کامپوننت‌های پروژه (طبق بخش
14 PRD) و صفحه لیست محصولات با قابلیت Filter و Sort کامل.

## وابستگی‌ها
فاز 00، 01 کامل باشند. داده‌های Mock محصولات (حداقل نسخه اولیه فاز 12)
لازم است.

## صفحات/Route های این فاز
- `/products` — همه محصولات
- `/products?category=...` — فیلتر بر اساس دسته (بخش 15، 46 PRD)

## Component های این فاز

### ProductCard (بخش 14 و 58 PRD) — یکبار ساخته و در کل سایت استفاده شود
اجزا:
- تصویر اصلی + تصویر Hover (فقط در Desktop).
- Badge (مثلاً «جدید»، «پرفروش»، «تخفیف»).
- دکمه Wishlist (Toggle).
- نام محصول، برند.
- Rating + تعداد Review.
- منطق قیمت:
  - بدون تخفیف → فقط قیمت اصلی.
  - با تخفیف → قیمت اصلی خط‌خورده + قیمت نهایی برجسته + درصد تخفیف.
- وضعیت موجودی (موجود/ناموجود).
- Quick Add (در صورت امکان طراحی).

الزامات فنی طبق بخش 58:
- کاملاً Clickable و قابل استفاده با Keyboard.
- Hover State مناسب.
- Image Ratio ثابت (بدون Layout Shift).
- سلسله‌مراتب بصری قیمت واضح.
- **یک طراحی یکسان در کل سایت** — بدون نسخه‌های موازی غیرضروری.

### ProductGrid
Wrapper مسئول چیدمان Responsive: در موبایل ترجیحاً 2 ستونه (بخش 7.1)،
در Desktop 3-4 ستونه.

### FilterSidebar (Desktop) / FilterSheet (Mobile) — بخش 15 PRD
فیلترها: دسته‌بندی، برند، سایز، رنگ، محدوده قیمت، تخفیف‌دار، امتیاز.
- Desktop: Sidebar کنار Grid.
- Mobile: Bottom Sheet/Drawer.
- نمایش تعداد فیلترهای فعال + دکمه پاک‌کردن همه.

### SortSelect
گزینه‌ها: جدیدترین، محبوب‌ترین، ارزان‌ترین، گران‌ترین، بیشترین تخفیف،
بالاترین امتیاز.

### Toolbar صفحه محصولات
شامل: Breadcrumb، عنوان صفحه، تعداد محصولات، دکمه Filter (موبایل)،
Sort، و احتمالاً Toggle نمای Grid/List.

### Pagination
کامپوننت عمومی صفحه‌بندی (از shadcn/ui، سفارشی‌سازی‌شده).

## جزئیات UX/UI
- تغییر Filter/Sort بدون Full Page Reload (Client-side State + URL Query
  Sync برای SEO و Share‌پذیری، طبق بخش 46).
- هنگام اعمال فیلتر، Grid باید Skeleton یا Fade نرم نشان دهد، نه پرش ناگهانی.
- سایز و رنگ ناموجود در فیلتر باید قابل تشخیص باشند (اما همچنان انتخاب‌پذیر
  برای دیدن نتیجه خالی — تصمیم UX قابل مستندسازی).

## داده‌های Mock مورد نیاز
- حداقل 20 محصول با ترکیب کامل از بخش 50 PRD: تخفیف‌دار/بدون تخفیف،
  Rating متفاوت، چند تصویر، چند رنگ، چند سایز، وضعیت موجودی متنوع.

## State های Loading / Empty / Error مرتبط
- Product Skeleton / Card Skeleton حین بارگذاری اولیه و حین اعمال فیلتر.
- Empty State: «نتیجه‌ای یافت نشد» با CTA پاک‌کردن فیلترها (بخش 41).
- Error State: خطای دریافت محصولات با Action «تلاش مجدد» (بخش 42).
