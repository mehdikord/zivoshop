# فاز 13 — QA & Final Review (فاز پایانی)

## هدف فاز

بازبینی نهایی کل پروژه در برابر معیارهای پذیرش PRD (بخش 62)، رفع
ناهماهنگی‌های بصری/تعاملی باقیمانده، و آماده‌سازی خروجی نهایی قابل
ارائه به‌عنوان یک محصول Premium — نه یک Demo ساده (بخش 64 PRD).

## وابستگی‌ها
تمام فازهای 00 تا 12 باید تکمیل شده باشند.

## فعالیت‌های این فاز

### 1. مرور چک‌لیست معیارهای پذیرش نهایی (بخش 62 PRD)
بررسی تک‌تک موارد زیر روی سایت واقعی:
- [ ] تمام صفحات اصلی ساخته شده‌اند.
- [ ] RTL در سراسر سایت کامل و بدون نقص است.
- [ ] Mobile UX در حد یک اپلیکیشن حرفه‌ای است.
- [ ] Bottom Dock موبایل در تمام صفحات مرتبط وجود دارد.
- [ ] Mega Menu کامل و کارکردی است.
- [ ] Product Listing دارای Filter و Sort کامل است.
- [ ] Product Detail کامل است (Gallery، Selectorها، Reviews).
- [ ] Cart کاملاً کار می‌کند.
- [ ] Wishlist کاملاً کار می‌کند.
- [ ] Checkout Flow سرتاسر کار می‌کند.
- [ ] Address Management (CRUD) کار می‌کند.
- [ ] Mock Payment با هر سه حالت (موفق/ناموفق/لغو) وجود دارد.
- [ ] Profile کامل است.
- [ ] Order History کامل است.
- [ ] تمام Loading/Empty/Error State ها وجود دارند (چک با فاز 10).
- [ ] تمام UI از Design Tokens استفاده می‌کند (بدون رنگ Hard-code).
- [ ] رنگ‌های برند Zivo در همه‌جا رعایت شده‌اند.
- [ ] فونت Vazirmatn در سراسر سایت استفاده شده.
- [ ] Componentها Reusable و بدون Duplicate هستند.
- [ ] هیچ صفحه اصلی با UI ناقص یا Placeholder رها نشده.
- [ ] Desktop و Mobile هر دو بررسی شده‌اند.

### 2. تست End-to-End جریان اصلی خرید (بخش 65 PRD)
مسیر کامل باید بدون اصطکاک قابل انجام باشد:
**کشف محصول → بررسی محصول → انتخاب سایز/رنگ → افزودن به سبد → انتخاب
آدرس → پرداخت → مشاهده سفارش در Profile**

### 3. Design/Brand Consistency Audit
- بررسی نسبت استفاده رنگ‌ها (60% Cream / 20% White Warm / 10% Brown /
  8% Gold / 2% Gold Dark — بخش 4.2) در صفحات کلیدی.
- بررسی یکدستی Product Card در سراسر سایت (بدون نسخه‌های موازی).
- بررسی یکدستی Spacing، Radius، Shadow طبق بخش 6.1.
- اطمینان از عدم استفاده افراطی از Gold (باید Accent بماند).

### 4. Accessibility & Performance Sweep (تکمیل فاز 11)
اجرای Lighthouse/axe روی صفحات کلیدی و رفع مشکلات باقیمانده.

### 5. Cross-device / Cross-browser Check
تست روی حداقل: یک مرورگر Desktop، Safari/Chrome موبایل، چند اندازه
صفحه (کوچک موبایل تا Large Desktop طبق Breakpoints بخش 7).

### 6. محتوای نهایی
اطمینان از اینکه هیچ متن Lorem Ipsum، تصویر Placeholder بی‌ربط یا داده
تستی نامناسب باقی نمانده (طبق اصول Agent بخش 60، مورد 14).

## معیار پذیرش نهایی (Definition of Done کل پروژه)
- [ ] تمام موارد چک‌لیست بخش 62 PRD به‌صورت عملی تست و تأیید شده‌اند.
- [ ] جریان کامل خرید بدون خطا از ابتدا تا انتها قابل انجام است.
- [ ] هیچ ناهماهنگی بصری یا Component تکراری باقی نمانده.
- [ ] خروجی نهایی حسی از یک فروشگاه Premium و واقعی می‌دهد، نه یک Demo
      ساده (بخش 64 PRD).

## خروجی این فاز
یک نسخه Release-candidate از سایت که آماده نمایش به ذی‌نفعان یا انتقال
به فاز اتصال Backend واقعی (خارج از Scope این Mock — بخش 61 PRD) است.
